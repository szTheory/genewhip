Specialization/integration ledger:
- Concrete instance-owned C17 arrays replace C++ templates, references and
  heap-owned operator/channel objects. Immutable logarithmic sine/power,
  envelope, detune and LFO tables are preserved verbatim from the pinned files.
- OPNA register layout is retained for the six-channel OPN2. Other chips,
  ADPCM/SSG engines, OPL rhythm/2-op and OPM noise are not part of the port.
  Debug formatting/wav writing and C++ save_restore are omitted; Genewhip's
  test digest explicitly serializes the chip state without pointers/padding.
- C17 asr supplies defined arithmetic-right-shift behavior. Narrowing and
  signed/unsigned conversions are explicit with the same masked/wrapped values.
- One YM sample per 1008 master ticks. Interface timers and busy use master/7
  clock deadlines; timer expiry precedes a coincident sample. IRQ state is
  maintained but is not connected to a Genesis CPU. No host clock is involved.
- Native output, including the discontinuity and DAC low test bit, is unchanged.
  The Genewhip stereo mix separately applies integer 3/4 (32768 -> 24576).
- The approved 03-FM-RESET-AMENDMENT.md wrapper applies upstream engine reset
  once on assertion, holds output silent and ignores writes while held. It
  preserves upstream-retained address/DAC/LFO/counters/busy state, master time,
  global sample grid, queued PCM and resampler continuation. Releasing reset
  does not restore FM keys; retained enabled DAC data may resume its DC level.
  Console-reset assertion is a model choice. Exact VA3 reset fidelity is unknown.
- References to other authors inside upstream comments describe upstream
  provenance, not additional sources read for this port.
