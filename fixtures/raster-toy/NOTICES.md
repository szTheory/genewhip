# Raster toy fixture notices

`src/toy.s` and `z80/driver.s` are original source solely authored for Genewhip under the repository MIT license (`../../LICENSE`). The 68000 start-up/interrupt code, palette, tile patterns, name tables and scroll tables are generated by assembler expressions in `src/toy.s`. The Z80 IM1 mailbox driver and its DAC triangle table are generated from the equations in `z80/driver.s`. Its small FM patch uses the same independently authored audible one-carrier register values established for Genewhip's `tests/devices/roms/z80/fm_script.s`; no external program, song or recorded sound is included.

## Assets and tool provenance

- No bundled assets are present. Graphics are emitted directly by the assembly source.
- The ROM is built with the source-built GNU Binutils 2.47 `m68k-elf-as` pinned by `../independent-game/toolchain.lock`, through `scripts/fixtures/build-original-roms.sh` (name `raster-toy`). No Binutils source or executable is bundled or linked into the ROM; upstream GPL-3.0-or-later notices are identified by path and digest in that lock.
- The guest bytes are assembled with the source-built GNU Binutils 2.47 `z80-elf-as` pinned by the same lock; `fixtures/manifest.json` records `z80_source`, `z80_include`, and both digests. The generated include is rebuilt twice from `z80/driver.s` before each enclosing ROM build. The DAC's 64 unsigned samples are an integer triangle generated by the source expression, not a third-party sample.
- Expected pixels live in `scenario.json` and `tests/devices/raster_toy.py`, derived from the constants in `src/toy.s` and the documented formats, never captured from Genewhip output.
- Sound assertions in `tests/devices/raster_toy_sound.py` parse the guest command, PSG divider/attenuation, FM key/F-number and DAC-table constants from guest source, then compare the public trace and PCM. The YM2612 idle sample has a retained DC baseline (native idle value 504 scaled by the 3/4 mix); pre-button silence therefore means no active Z80 trace and no temporal AC activity after resampler startup, not an all-zero PCM buffer.

This fixture is original diagnostic evidence for the Genewhip renderer. It is not independent-game compatibility evidence.
